# 라운드 코치 연결 계약

2026-09-21 사용자는 무료 Gemini 프로젝트/키가 준비되지 않았으며 미연결 UI와 서비스 인터페이스로 진행하도록 답했다. 실제 AI API, 음성 입력, 음성 출력은 미연결이다. 비밀키나 유료 서비스를 설정하지 않았다.

## 텍스트 인터페이스

`RoundCoach.configureService(null)`이 기본 상태다. 질문과 음성 버튼은 비활성화하고 실제 저장된 운동 기록 요약만 표시한다. API가 없는 상태에서 고정 문장을 AI 답변으로 표시하지 않는다.

향후 검증된 서버 어댑터를 `RoundCoach.configureService({reply})`로 연결한다. 팝업이 열린 중에는 변경할 수 없다. 브라우저 어댑터에 제공자 비밀키를 넣지 않는다. 서버 측 인증/센터 권한과 무료 등급 검증을 완료하기 전 실제 제공자 어댑터를 활성화하지 않는다.

`reply({summary, history, question, language, signal})`은 `{text}`를 반환하는 Promise다. `language`는 `ko`다. `signal`의 취소를 지원해야 하며 클라이언트는 취소를 무시하는 어댑터의 늦은 응답도 폐기한다. 질문은 최대 2,000자, 응답은 최대 16,000자다. 중복 전송은 차단하며 기본 응답 대기는 20초다. 실패 시 질문을 남겨 다시 보낼 수 있고 자동 재전송하지 않는다.

운동 요약은 운동 시간, 시험/미평가 상태, 네 가지 동작 횟수, 총점, 평균 품질만 포함한다. 이름·회원 ID·센터 ID·세션 ID·원본 이벤트/좌표·영상은 제공자에게 전달할 요약에 포함하지 않는다. 사용자 질문과 최근 20개 대화 메시지는 대화 서비스로 전달될 수 있음을 입력창 위에 표시한다. 사용자가 질문에 직접 입력하는 정보는 이 전송 경로에 포함된다.

답변은 텍스트 노드로 표시하며 HTML을 실행하지 않는다. 응답에 점수 등 다른 필드가 있어도 저장된 라운드 결과를 변경하지 않는다. 현재 대화는 메모리에만 보관하고 종료/로그아웃 시 지운다. SQLite/Supabase나 직원 조회 API에 대화 기록을 저장하지 않는다. 운동 요약과 점수는 기존 라운드 저장 권한을 따른다.

## 음성 상태

`configureService`의 선택적 `voice` 객체로 음성 서비스를 연결한다. 기본은 미연결이며 마이크를 자동으로 켜지 않는다. 음성 서비스는 `stop()`과 `listen(request)` 또는 `speak(request)`를 제공해야 해당 버튼이 활성화된다. `stop()`은 수집 트랙과 재생을 즉시 중단하고 자원을 해제하는 계약이다.

공통 요청은 `{language:'ko', signal, onStart, onLevel}`이며 `speak`에만 `text`가 추가된다. `listen`은 최종 `{text}`를 반환하고 `speak`는 실제 재생 종료 시 완료한다. 입력은 사용자의 음성 입력 버튼에서만 시작하며 인식 문장은 입력창에 표시한다. 외부 AI 전송은 사용자가 전송 버튼으로 확정한다. 입력을 시작하면 이전 재생을 중단하고, 재생을 시작하면 입력을 중단한다. 채팅 전송/종료/로그아웃도 음성을 중단한다. 실제 제공자 어댑터는 중단 계약을 준수해야 하며 아직 연결·검증되지 않았다.

`onStart()`는 권한 요청 시점이 아닌 실제 수집/재생 시작에 호출한다. 출력의 `onLevel(0..1)`은 실제 재생 오디오에서 측정한 정규화 진폭만 전달한다. 재생 시작 전·종료 후 값은 무시하고 150ms 동안 새 값이 없으면 0으로 복귀한다. 진폭이 없는 제공자는 `onLevel`을 호출하지 않으며 화면은 재생 상태만 표시한다. 텍스트 길이나 타이머로 가짜 발화 진폭을 만들지 않는다.

입력 30초/출력 120초 제한, `NotAllowedError` 권한 거부, 실패/재시도, 늦은 인식 결과/진폭 무시, 명시적 음성 중단 버튼을 구현했다. 원본 음성은 앱의 라운드/대화 저장소에 저장하지 않는다. 실제 음성의 처리 위치와 외부 전송 여부는 제공자 선택 시 별도로 검증해야 한다. 현재는 브라우저 음성 API, 마이크, WebView2, 실제 오디오 재생을 사용하지 않았고 합성 어댑터로 인터페이스만 검증했다.

## 검증

`test_coach_voice.mjs`: 명시적 시작, 입력/재생 상호 중단, 권한 거부, 시간 초과, 종료 후 진폭/입력 무시를 합성 제공자로 검사한다. 팝업 브라우저 검사에도 합성 음성 문장의 입력창 반영과 재생 중 종료/진폭 연결을 포함한다. 이 결과는 실제 발화 동기화 측정이 아니다.

`test_coach_conversation.mjs`: 요약의 개인정보 제외, 요청 중복 차단, 요약 복사본 격리, 응답으로 점수 변경 불가, 응답 시간 초과, 미연결, 종료 후 응답 무시를 합성 어댑터로 검사한다.

`test_round_coach_browser.js`: 기본 미연결 UI, 합성 어댑터 연결 후 질문/응답, HTML 문자열 비실행, 대기 중 채팅 종료와 늦은 응답 무시, 반응형/테마/명시적 종료를 검사한다. 실제 Gemini 응답이나 음성 지원 증거가 아니다.
# 저장된 가드 관측 요약 (2026-09-22)

보고서 v1 이벤트의 선택 필드 `guard_ratio`는 동작 궤적에서 반대손이 가드 범위에 있었던 표본 비율이다. 실제 타격 정확도나 전체 라운드 가드 유지 시간 비율이 아니다. 원투는 구성 펀치의 비율을 평균한다. 서버는 유한한 0~1 숫자만 허용하며 점수 산식을 변경하지 않는다. 기존 보고서에 필드가 없으면 가드를 평가하지 않는다.

팝업은 저장된 비율 0.9 이상인 이벤트를 긍정 관측으로, 0.5 미만이 2개 이상일 때 반복 관측으로 안내한다. 이는 AI 생성 답변이 아닌 시험 관측 집계다. 외부 대화 인터페이스에는 평가/유지/낮음의 이벤트 개수와 추적 공백 총시간을 추가하며 개별 이벤트·좌표·회원 정보는 보내지 않는다. 추적 구간 저장은 [추적 보고서](11-tracking-evidence.md)를 따른다.
