# 1단계 상태 재구성

2026-09-16에 현재 작업 트리를 확인했다. 이 경로의 기존 인수인계 문서는 없었으므로 `../ENGINE_REMOVAL.md`와 실제 코드를 함께 점검했다. 기존 미커밋 변경은 보존한다.

- `web/scripts/session.js`는 카메라·녹화·기본 세션을 담당하고 `backend/camera.py`는 캡처 메타데이터만 허용한다.
- 기존 포즈·보정·피드백 모듈 및 MediaPipe 자산은 삭제된 상태다. 보정/포즈 API는 제거됐고 과거 DB 필드·마이그레이션은 남아 있다.
- 2단계 변경 전 Python 57개 및 Android JavaScript 테스트가 통과했다. 실행한 테스트의 DB 사용을 검토했으며 메모리/임시 DB만 사용했다.
- 제거 단계가 인증·DB 안전성까지 보증하지는 않는다. `Store.__init__`에 자동 마이그레이션과 고정 계정 비밀번호 재설정이 남아 있고, Android 토큰은 사용자 ID로 구성돼 있다. 2단계에서 수정한다.

상세 제거 내역: [기존 보고서](../ENGINE_REMOVAL.md). 다음 단계: [백엔드 안정화](02-backend.md).
