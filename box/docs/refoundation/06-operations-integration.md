# 업무 구현·전환·검증 — 2026-09-20

## 구현 완료

웹 0.7.0, PWA 캐시 boxingcoach-shell-2026-09-20-1. 대시보드 설명과 반복 부연을 제거하고 회원 수정/삭제 버튼, 표 세로 정렬, 센터·설정 화면 폭을 정리했다. 필요한 오류·삭제 확인·직원 서비스 미연결 표시는 유지한다. 운동 세션 화면 개편은 하지 않았다.

센터 공통 연락처·주소·평일/주말 운영시간은 operation_center_details와 center.save에 연결했다. 센터 연락과 방문 안내에 필요한 항목이며 초기 값은 빈 값이다. 기존 브라우저의 연락처를 자동 업로드하지 않는다. 라운드는 장치 설정으로 분/초를 합쳐 초 단위로 저장한다. 링·샌드백은 UI에서만 제거했다.

회원 메모는 기존 injury_note이며 본인 조회도 가능하다. 직원 전용 상담 메모와 구분한다. 선택 이용권 만료일과 프로필을 원자 저장하고 SET_END 이력을 남긴다. 등록일을 보존하고 이용권 없는 회원에게 만료일을 생성하지 않는다. 복수 이용권은 하나를 선택한다. PAUSED/UPCOMING/NONE은 필터에서 제외하고 배지는 ‘—’로 표시하며 데이터·회원·이력은 보존한다.

KAKAOPAY/EASY_PAY는 수납 사실 기록이다. 월별 차트는 발생월의 수납−환불/수납 취소이며 비용 차감 전 금액이다. 실제 승인·송금·웹훅은 미구현이다. 출석 최초/재진입은 센터 오늘이며 오늘 조회 중 60초/포커스 복귀 갱신, 과거 선택 유지 정책이다. 입력/모달 중 자동 조회하지 않는다.

## 실제 staging 검증 완료

적용 전 boxingcoach-staging의 정상 상태, Auth 0명/public 테이블 0개/Edge 0개/이력 없음을 확인했다. 16개 마이그레이션을 순서대로 적용하고 source_hash를 이력에 저장했다. admin-create-user와 register-member를 JWT 검증을 유지하여 배포했다. 사용자 별도 승인으로 이메일 자동 확인과 custom_access_token_hook을 staging에만 활성화했다.

tools/staging_smoke.py로 실제 플랫폼/소유자/코치/회원 로그인, Edge 회원 등록 및 동일 요청 재시도, 프로필/선택 만료일/SET_END, 카카오페이 수납/부분 환불, 출석/중복 거부, 센터 재조회, 코치/회원 권한 거부를 확인했다. 별도 센터 소유자로 첫 센터 회원·이용권 조회 격리 및 회원/센터/수납 변경 거부를 확인했다. REST P0002(대상 없음)는 HTTP 500으로 전달될 수 있어 검증 도구는 SQL 코드를 함께 확인한다.

합성 계정 설정은 Git 제외 artifacts/staging-smoke-accounts.json에만 있다. .env.staging.local의 관리 토큰은 서버 요청에만 사용하며 출력하지 않는다. 운영 프로젝트는 변경하지 않았다. 배포된 중앙 웹과 실제 네이티브 앱의 종단 테스트는 별도다.

## 개발 DB 적용 완료·미검증 환경

사용자 별도 승인 후 기존 개발 DB를 artifacts/development-schema2-backup-20260920-190923.db로 백업하고 schema 3으로 전환했다. 기존 18개 테이블의 5개 레코드와 관리자 비밀번호 해시가 동일하다. 기존 센터의 Asia/Seoul 기본 시간대 행 1개가 추가됐으며 FK 오류 0개, 무결성 정상이다. artifacts/development-db.txt가 가리키는 동일 DB로 서버를 재시작하고 기존 admin 로그인과 업무 snapshot 조회를 확인했다. 비밀번호를 초기화하거나 DB를 교체하지 않았다.

staging에서 확인한 P0002 HTTP 500 응답은 중앙 게이트웨이에서 404로 변환하여 로컬 API 계약과 맞췄다. 다른 서버 오류는 그대로 유지하며 관련 게이트웨이 18개 검사를 통과했다.

실제 WebView2/Android·카메라 하드웨어, 운영 배포는 미검증이다. 이전 WPF build·SmokeTests 3개 기록은 유지하며 이번 네이티브 수정은 없다. 직원 업무 서비스·PG·알림은 범위 밖이다. 커밋·푸시와 기존 사용자 데이터 삭제는 하지 않았다.
