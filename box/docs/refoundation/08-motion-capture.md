# 섀도복싱 촬영·라벨 평가 안내

현재 실제 영상은 준비되지 않았다. 아래는 초기 자료 수집 절차이며 아직 정확도를 검증했다는 뜻이 아니다. 원본은 Git 제외 `artifacts/motion-evaluation/`에 보관하며 외부 AI로 전송하지 않는다.

2026-09-21 사용자가 영상이 없으므로 실제 영상 검증을 제외하고 우선 진행하도록 지시했다. 다음 촬영 안내는 향후 검증용이며 이번 구현 진행을 막는 선행 조건으로 삼지 않는다. 실제 정확도와 권장 각도는 미검증으로 남긴다.

## 1차 비교 촬영

카메라를 고정하고 머리부터 발까지, 양손을 뻗어도 화면 밖으로 나가지 않게 촬영한다. 우선 익숙한 스탠스로 편하게 수행한다. 정면과 정면에서 약 20~30도 이동한 얕은 대각선에서 같은 순서를 반복한다. 이 각도는 비교 후보이며 최종 권장 각도가 아니다.

각 각도에서 약 2분:

1. 가드 상태 10초. 사용하는 스탠스를 영상 시작에 말하거나 별도 텍스트로 기록.
2. 잽 5회, 각 동작 후 가드로 돌아와 2초 정도 간격.
3. 왼손/오른손 훅 각각 5회.
4. 왼손/오른손 어퍼 각각 5회.
5. 원투 5회. 원투 사이에는 잠깐 멈춤.
6. 약 20초간 평소 속도의 자유 섀도복싱.
7. 약 20초간 펀치 없이 가드 조정·스텝·머리 만지기 등 일상 움직임.

파일 이름 예: `person01_front_orthodox_dev.mp4`, `person01_diagonal_orthodox_dev.mp4`. 실제 이름을 넣을 필요는 없다. 최소 30 FPS 원본을 유지하고 슬로모션·프레임 보간·미러 편집은 하지 않는다. 원본이 미러 영상이면 알려준다.

처음부터 많은 영상을 요구하지 않는다. 위 두 영상으로 병목과 혼동을 확인한 후 반대 스탠스·다른 조명/거리·다른 사람·연속 펀치 자료를 보강한다. 익숙하지 않은 스탠스는 무리해서 수행할 필요가 없다.

## 최종 평가 분리

모델/규칙을 조정한 영상은 development다. 조정 후 별도 촬영한 영상을 evaluation으로 지정하며 결과를 보고 다시 조정하면 해당 영상도 development로 전환한다. 한 사람·한 각도 결과를 전체 사용자 정확도로 일반화하지 않는다.

## 정답 형식

영상 시작을 0ms로 한다. start_ms는 펀치 시작, end_ms는 회수를 완료한 시점이다. 원투는 두 펀치 전체를 한 이벤트로 라벨링하고 구성 잽을 중복 기입하지 않는다. 손/스탠스/각도는 별도 메타데이터로 기록한다. 판정이 모호한 구간은 먼저 사람이 검토하고 임의 정답을 만들지 않는다.

```json
{
  "clip_id": "person01_front_orthodox_dev",
  "split": "development",
  "duration_ms": 120000,
  "events": [
    {"id": "event001", "label": "jab", "start_ms": 10500, "end_ms": 11200}
  ],
  "negative_intervals": [{"start_ms": 0, "end_ms": 10000}]
}
```

예시 시간은 형식 설명용이며 실제 영상 정답이 아니다. 예측 파일은 같은 clip_id와 events 구조를 사용한다. label은 jab/hook/uppercut/one_two다. 비동작 구간은 명시적으로 표시하고 동작과 겹치면 평가를 거부한다.

box/에서 `python tools/evaluate_motion.py --truth artifacts/motion-evaluation/labels.json --predictions artifacts/motion-evaluation/predictions.json`으로 평가한다. 시간 순서와 완료 시점 오차로 일대일 연결한 뒤 라벨을 비교한다. 정답 라벨을 이용해 유리한 연결을 선택하지 않는다. 기본 허용 오차는 350ms이며 최종 평가 전에 고정한다. 정밀도·재현율·혼동표·미매칭 예측·비동작 분당 오탐을 출력한다. 표본이 없으면 null이며 100%로 표시하지 않는다. 실제 피드백 지연은 별도의 발행 시각 측정이 필요하다.

## 영상에서 예측 파일 생성

로컬 모델 설치 후 box/에서 실행한다. 기존 결과 파일은 덮어쓰지 않는다.

```powershell
node tools/predict_motion_video.cjs --video artifacts/motion-evaluation/person01_front_orthodox_dev.mp4 --output artifacts/motion-evaluation/predictions.json --clip-id person01_front_orthodox_dev --stance orthodox
```

Chrome에서 영상을 실시간 속도로 재생하며 앱과 같은 Worker·특징 추출·시간 판정·라운드 집계를 사용한다. 외부 주소 요청을 차단하고 모델/스크립트는 임시 루프백 서버에서만 읽는다. 영상은 로컬 파일 입력으로 열며 앱 DB와 녹화 기록에 저장하지 않는다. 원본 SHA-256, 모델 SHA-256, 모델/실행 장치, 이벤트 및 추론/표시 콜백 수와 지연을 결과에 포함한다. 현재 MediaPipe 어댑터용이며 MoveNet의 깊이 판정 비교를 완료한 도구가 아니다.

`--delegate CPU` 또는 `--delegate GPU`로 후보를 비교할 수 있다. 기본은 설치 manifest 설정이다. `--synthetic true`는 실제 영상 대신 3초 빈 영상을 생성하는 배선 검사이며 사람 동작 평가가 아니다. 측정한 표시 FPS는 영상 재생 콜백 기준이고 실제 카메라 FPS·동시 녹화 부하·운영체제 자원 사용량을 대체하지 않는다.

정답 이벤트에 `hand: left|right|both`를 선택적으로 추가하면 같은 동작 라벨로 시간 매칭된 이벤트의 신체 좌우 오류율을 계산한다. 원투만 both다. 정답에 `input_sha256`을 추가하면 다른 영상 결과와의 비교를 거부한다. 결과 `score_publications`가 있으면 사람이 라벨링한 회수 시점부터 점수 DOM 갱신까지의 지연을 계산한다. 실제 화면 표시 완료나 5초 코칭 피드백 지연과는 다르며 조기 발행은 음수로 보존한다. 라운드 종료 때 확정된 잽은 실시간 발행 지연 통계에서 제외하고 `finalized_on_end_ids`로 따로 표시한다.
