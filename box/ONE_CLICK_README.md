# BoxingCoach One-Click Portable

1. Unzip the package.
2. Double-click `START_BOXING_COACH.bat`.
3. The server starts and opens the app in your browser.
4. Close the black server window to stop the app.

No Python installation is required. The package includes a portable Python runtime and installed dependencies from the build machine.

Notes:

- Real-time pose tracking runs in the browser with MediaPipe.
- Windows may show a SmartScreen warning because this is an unsigned local build.
