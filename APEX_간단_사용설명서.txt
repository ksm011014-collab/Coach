============================================================
              APEX Boxing AI Coach 간단 사용 설명서
============================================================


------------------------------------------------------------

------------------------------------------------------------

1. 프로그램을 실행합니다.
   - 바탕화면 또는 프로그램 폴더의 실행 파일
Boxing coach
을 두 번 클릭합니다.
   - 실행 후 인터넷 창에 로그인 화면이 나타납니다.

2. 카메라를 준비합니다.
   - 운동할 사람의 머리부터 발끝까지 화면에 보여야 합니다.
   - 주변을 밝게 하고, 카메라 앞에 한 사람만 서는 것이 좋습니다.
   - 카메라 사용 여부를 묻는 창이 나오면 반드시 [허용]을 누릅니다.

3. 왼쪽 메뉴가 보이지 않을 때
   - 화면 왼쪽 위의 메뉴 펼치기 버튼을 누릅니다.

4. 테스트용 기본 계정
   - 관리자 아이디: owner
   - 관리자 비밀번호: Owner!123
   - 회원 아이디: member
   - 회원 비밀번호: Member!123
   ※ 실제 운영을 시작하면 테스트 비밀번호를 그대로 사용하지 마세요.


============================================================
   [탭 1] 관리자용
============================================================

[관리자가 가장 먼저 할 일]

관리자 로그인 → 센터 정보 확인 → 회원 등록 → 카메라 설정
→ 운동할 회원 선택 → 실시간 코칭 시작 → 운동 기록 확인


1. 관리자 로그인하기
------------------------------------------------------------

1) 로그인 화면 위쪽에서 [관리자]를 누릅니다.
2) 관리자 아이디와 비밀번호를 입력합니다.
3) [로그인]을 누릅니다.
4) 로그인되면 왼쪽에 관리자 메뉴가 나타납니다.

새 센터를 처음 만드는 경우
1) 로그인 화면 아래의 [센터/회원 가입하기]를 누릅니다.
2) 가입 유형에서 [관리자: 새 센터 생성]을 선택합니다.
3) 센터명, 아이디, 이름, 이메일, 비밀번호 등을 입력합니다.
4) 아이디 옆의 [중복 확인]을 먼저 누릅니다.
5) 입력을 마친 뒤 [가입하기]를 누릅니다.


2. 관리자 화면 메뉴 이해하기
------------------------------------------------------------

[실시간 코칭]
- 카메라를 사용해 회원의 복싱 동작을 측정하고 피드백을 보여줍니다.

[대시보드]
- 전체 회원 수, 출석 회원, 최근 운동 기록과 점수를 한눈에 봅니다.

[센터 정보]
- 센터 이름, 운영 정보, 수업 관련 정보를 확인하거나 수정합니다.

[회원 관리]
- 회원을 새로 등록하고 정보를 수정합니다.
- 회원별 운동 기록, 점수, 녹화 영상과 피드백을 확인합니다.

[직원]
- 직원 정보를 등록하고 담당 업무를 관리합니다.

[출석]
- 날짜별 출석 회원을 달력으로 확인합니다.

[설정]
- 화면 테마, 알림, 음성, 효과음, 카메라와 계정 정보를 설정합니다.


3. 회원 등록하기
------------------------------------------------------------

1) 왼쪽 메뉴에서 [회원 관리]를 누릅니다.
2) 화면 아래쪽의 [회원 등록]을 누릅니다.
3) 회원 아이디, 이름, 이메일과 비밀번호를 입력합니다.
4) 생년, 성별과 운동 레벨을 선택합니다.
5) [등록]을 누릅니다.
6) 등록한 아이디와 비밀번호를 회원에게 알려줍니다.

꼭 확인하세요.
- 비밀번호는 특수문자를 포함하여 8자 이상으로 만듭니다.
- 회원 이름과 연락처를 정확히 입력하면 검색하기 쉽습니다.
- 키 정보는 동작 보정에 사용되므로 실제 키를 입력하는 것이 좋습니다.


4. 회원 정보 수정하기
------------------------------------------------------------

1) [회원 관리]에서 수정할 회원을 찾습니다.
2) 회원 오른쪽의 [수정]을 누릅니다.
3) 이름, 연락처, 키, 몸무게, 레벨, 스탠스 등을 수정합니다.
4) [수정 완료]를 누릅니다.

회원이 많을 때는 검색칸에 이름이나 연락처를 입력하면 빠르게 찾을 수 있습니다.


5. 카메라 설정하기
------------------------------------------------------------

6. 회원의 실시간 코칭 시작하기
------------------------------------------------------------

가장 안전한 시작 방법
1) [회원 관리]에서 운동할 회원의 [운동 기록]을 누릅니다.
2) 해당 회원 영역의 [Start Coaching]을 누릅니다.
3) 카메라 사용을 묻는 창이 나오면 [허용]을 누릅니다.
4) 회원이 카메라에서 2~3걸음 떨어져 전신이 보이게 섭니다.
5) 실시간 코칭 화면에서 [시작]을 누릅니다.

운동 중 화면 보는 방법
- 수행 동작: 지금 따라 해야 할 동작입니다.
- 점수: 현재 동작이 얼마나 정확한지 보여줍니다.
- AI 피드백: 자세를 어떻게 고치면 되는지 알려줍니다.
- 운동 기록: 운동 시간과 진행 상태를 보여줍니다.

운동 중 주의사항
- 한 번에 한 명만 카메라 앞에 섭니다.
- 몸이 화면 밖으로 나가지 않게 합니다.
- 너무 어둡거나 뒤에서 강한 빛이 들어오지 않게 합니다.
- 동작은 급하게 하지 말고 화면의 안내에 맞춰 정확히 합니다.


7. 운동 종료하고 결과 확인하기
------------------------------------------------------------

1) 운동이 끝나면 실시간 코칭 화면의 [종료]를 누릅니다.
2) 점수와 피드백 결과를 확인합니다.
3) 왼쪽 메뉴의 [회원 관리]로 이동합니다.
4) 해당 회원의 [운동 기록]을 누릅니다.

운동 기록에서 할 수 있는 일
- 운동 날짜, 운동 시간과 점수 확인
- [녹화 보기]로 저장된 영상 확인
- [다운로드]로 영상 파일 저장
- [피드백 저장]으로 결과 파일 저장
- 필요 없는 기록을 선택한 뒤 [선택 삭제]

※ 삭제한 기록은 되돌리기 어려우므로 회원 이름과 날짜를 꼭 확인하세요.


8. 출석과 운영 현황 확인하기
------------------------------------------------------------

[대시보드]
1) 왼쪽 메뉴에서 [대시보드]를 누릅니다.
2) 회원 수, 출석 수, 최근 운동과 점수 순위를 확인합니다.

[출석]
1) 왼쪽 메뉴에서 [출석]을 누릅니다.
2) 달력에서 확인할 날짜를 누릅니다.
3) 오른쪽에서 해당 날짜의 출석 회원을 확인합니다.


9. 관리자 설정 바꾸기
------------------------------------------------------------

1) 왼쪽 메뉴에서 [설정]을 누릅니다.
2) 필요한 항목을 바꿉니다.
   - 테마: 어두운 화면 또는 밝은 화면 선택
   - 세션 알림: 운동 종료 알림 켜기/끄기
   - 음성 피드백: 안내 음성 켜기/끄기
   - 효과음: 시작과 종료 소리 켜기/끄기
   - 계정 설정: 관리자 정보 수정
3) [설정 저장]을 누릅니다.


============================================================
                    [탭 2] 회원용
============================================================

[회원이 가장 먼저 할 일]

회원 로그인 → 내 정보 확인 → 카메라 허용 → 실시간 코칭 시작
→ 안내 동작 따라 하기 → 운동 종료 → 내 운동 기록 확인


1. 회원 로그인하기
------------------------------------------------------------

1) 로그인 화면 위쪽에서 [회원]을 누릅니다.
2) 관리자에게 받은 회원 아이디와 비밀번호를 입력합니다.
3) [로그인]을 누릅니다.
4) 로그인되면 왼쪽에 회원용 메뉴가 나타납니다.

센터 코드로 직접 가입하는 경우
1) 로그인 화면 아래의 [센터/회원 가입하기]를 누릅니다.
2) 가입 유형에서 [회원: 센터 코드로 가입]을 선택합니다.
3) 관리자에게 받은 센터 코드를 입력합니다.
4) 아이디, 이름, 이메일, 비밀번호 등을 입력합니다.
5) 아이디 옆의 [중복 확인]을 먼저 누릅니다.
6) [가입하기]를 누릅니다.


2. 회원 화면 메뉴 이해하기
------------------------------------------------------------

[실시간 코칭]
- 카메라를 켜고 AI 복싱 코칭을 시작합니다.

[운동 현황]
- 내 운동 횟수, 평균 점수, 최고 점수와 운동 기록을 봅니다.

[출석]
- 내가 운동한 날짜를 달력으로 확인합니다.

[정보 변경]
- 이름, 연락처, 키, 몸무게, 스탠스와 주의사항을 수정합니다.

[설정]
- 화면 테마, 알림, 음성, 효과음과 카메라를 설정합니다.


3. 내 정보 확인하고 수정하기
------------------------------------------------------------

처음 운동하기 전에 키 정보를 입력하는 것이 좋습니다.

1) 왼쪽 메뉴에서 [정보 변경]을 누릅니다.
2) 이름, 전화번호, 생년월일, 성별을 확인합니다.
3) 키와 몸무게를 실제 정보에 맞게 입력합니다.
4) 오른손잡이는 오소독스, 왼손잡이는 사우스포를 선택합니다.
5) 다친 곳이나 조심해야 할 부위가 있으면 주의사항에 입력합니다.
6) [정보 저장]을 누릅니다.


4. 실시간 코칭 시작하기
------------------------------------------------------------

1) 왼쪽 메뉴에서 [운동 현황]을 누릅니다.
2) [실시간 코칭 시작]을 누릅니다.
   또는 왼쪽 메뉴에서 [실시간 코칭]을 누릅니다.
3) 카메라 사용을 묻는 창이 나오면 [허용]을 누릅니다.
4) 카메라에서 2~3걸음 떨어져 전신이 보이게 섭니다.
5) 화면의 [시작]을 누릅니다.

처음 운동할 때 보정 화면이 나오면
1) 카메라 중앙에 섭니다.
2) 머리부터 발끝까지 모두 보이는지 확인합니다.
3) 팔을 조금 벌린 A자 자세를 유지합니다.
4) 안내에 따라 제자리에서 천천히 회전합니다.
5) 완료 안내가 나오면 코칭을 시작합니다.


5. 운동하면서 화면 보기
------------------------------------------------------------

[수행 동작]
- 화면에 표시된 잽, 스트레이트, 훅 등의 동작을 따라 합니다.

[점수]
- 자세와 동작이 정확할수록 점수가 올라갑니다.
- 점수가 낮아도 서두르지 말고 피드백을 하나씩 따라 하면 됩니다.

[AI 피드백]
- 손 위치, 펀치 뻗기, 자세 등에 대한 안내가 표시됩니다.
- 음성 피드백을 켜면 안내를 소리로 들을 수 있습니다.

[운동 시간]
- 현재까지 운동한 시간을 확인할 수 있습니다.

정확하게 측정되는 자세
- 얼굴과 양손이 카메라에 보이게 합니다.
- 무릎과 발끝이 화면 밖으로 나가지 않게 합니다.
- 다른 사람이 카메라 앞을 지나가지 않게 합니다.
- 몸에 너무 헐렁한 옷보다 팔과 다리 움직임이 보이는 옷이 좋습니다.


6. 운동 끝내기
------------------------------------------------------------

1) 운동을 마치려면 화면의 [종료]를 누릅니다.
2) 최종 점수와 AI 피드백을 확인합니다.
3) 결과 창을 닫으면 운동 기록이 저장됩니다.

※ 창을 바로 닫거나 프로그램을 강제로 종료하지 말고 먼저 [종료]를 누르세요.


7. 내 운동 기록 확인하기
------------------------------------------------------------

1) 왼쪽 메뉴에서 [운동 현황]을 누릅니다.
2) 총 운동 횟수, 평균 점수, 최고 점수와 누적 시간을 확인합니다.
3) 아래의 운동 기록 표에서 날짜별 결과를 확인합니다.
4) 녹화된 운동은 [녹화 보기]를 눌러 다시 볼 수 있습니다.


8. 내 출석 확인하기
------------------------------------------------------------

1) 왼쪽 메뉴에서 [출석]을 누릅니다.
2) 달력에서 색이 표시된 날짜를 누릅니다.
3) 해당 날짜의 운동 횟수와 시간을 확인합니다.


============================================================
                    자주 막히는 문제 해결
============================================================

[로그인이 안 됩니다]
- 관리자용인지 회원용인지 탭을 먼저 확인합니다.
- 영어 대문자와 소문자가 맞는지 확인합니다.
- 키보드의 Caps Lock이 켜져 있는지 확인합니다.
- 계속 안 되면 관리자에게 아이디와 비밀번호를 다시 확인합니다.

[카메라 화면이 나오지 않습니다]
- 화면의 [카메라 연결] 또는 다시 시도 버튼을 누릅니다.
- 인터넷 창 주소 왼쪽의 자물쇠/설정 아이콘을 눌러 카메라를 [허용]으로 바꿉니다.
- 다른 화상회의 프로그램이 카메라를 사용 중이면 종료합니다.
- 카메라 선을 다시 연결한 뒤 [설정]에서 [카메라 검색]을 누릅니다.

[몸을 잘 인식하지 못합니다]
- 밝은 곳으로 이동합니다.
- 카메라에서 조금 더 멀리 섭니다.
- 머리부터 발끝까지 전신이 보이게 합니다.
- 배경과 비슷한 색의 옷은 피합니다.
- 화면에는 운동하는 한 사람만 나오게 합니다.

[점수가 계속 낮게 나옵니다]
- 빠르게 하기보다 동작을 천천히 정확하게 합니다.
- 양손을 얼굴 가까이에 두고 기본 가드를 유지합니다.
- AI 피드백 문장을 한 가지씩 따라 합니다.
- 카메라가 흔들리지 않게 고정합니다.

[소리가 나오지 않습니다]
- [설정]에서 [음성 피드백]과 [효과음]을 켭니다.
- 컴퓨터 또는 태블릿의 음량과 음소거 상태를 확인합니다.
- [음성 테스트] 또는 [효과음 테스트]를 누릅니다.


------------------------------------------------------------
[안전 안내]
------------------------------------------------------------

- 운동할 공간 주변의 의자, 물건과 전선을 치웁니다.
- 통증이나 어지러움이 있으면 즉시 운동을 멈춥니다.
- 카메라와 화면만 보느라 주변 사람이나 물건과 부딪히지 않게 합니다.
